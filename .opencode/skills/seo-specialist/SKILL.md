# SEO Uzmanı Skill

> Bu standartlar hem web hem AI için geçerlidir → detay: `standards/seo/AI_CAĞI_SEO_STANDARTLARI.md` [EK-20260923]

Kaynak: APP-FABRIKA `governance/market/` (DEMAND_INTELLIGENCE_SYSTEM, MARKET_DEMAND_RESEARCH, QUARTERLY_GROWTH_SCORECARD), `governance/linguistic/DEPARTMENT_CHARTER.md`, `05-templates/web-app/BLUEPRINT.md` (opencode'a uyarlandı)

## Repodan alınan standartlar

- **SEO meta baseline:** Web uygulama launch checklist'inde zorunlu madde (`05-templates/web-app/BLUEPRINT.md`).
- **Long-tail strateji:** SEO + blog + backlink — long-tail, arama niyeti odaklı (organik dağıtımda ~%25 pay).
- **Kullanıcı dili:** Long-tail, kullanıcı dili, JTBD landing (`linguistic` charter).
- **Arama niyeti:** SEO/ASO kelime → content title eşlemesi; `demand_output/search_intent/` çıktısı.
- **Rakip trafik/SEO:** Rakip trafik analizi keşif sisteminin bir adımı.
- **Kanal dağılımı (referans):** ASO %30 · SEO %25 · Sosyal %20 · Topluluk %15 · Viral %10 (Yıl 1 organik hedef dağılımı).

## Çalışma kuralları

- Analizleri kanıt tabanlı üret; pazar verisi yoksa varsayım yapma, veri toplama adımı öner (web search / MCP tarayıcı).
- SEO kararları CPO → CAO denetim zincirine tabidir.
- Landing/ içerik önerilerinde kullanıcı dili ve JTBD çerçevesini kullan.

## Standart boşluğu (varsayım yapılmaz)

- **Teknik SEO detayları:** APP-FABRIKA repoda SEO yalnızca meta baseline ve pazarlama/keşif kanalı olarak geçiyor; sitemap, structured data (schema.org), Core Web Vitals eşikleri, canonical stratejisi gibi teknik SEO kuralları **repoda yok**. Kamelya projesi bunları gerektiriyorsa geliştirici tarafından tanımlanmalı ve bu skill'e eklenmelidir (F2 fazı öncesi).
