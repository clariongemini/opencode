## 6. Keşif / Notlar

- `sss_sorulari` üzerinde `sira` unique key **yok** → migration idempotence SELECT-by-sira + UPDATE/INSERT ile sağlandı.
- `sss_cevirileri` `UNIQUE(soru_id, dil_kodu)` · `seo_verileri` `UNIQUE(sayfa_tipi, sayfa_kodu, dil_kodu)` → `ON DUPLICATE KEY UPDATE` doğrudan çalışır.
- SEO meta üretimi ilk denemede bant dışına düştü (title 63B / desc 201B); UTF-8 byte hedefli elle yazım ile 6/6 dil bant içine alındı.
- Seed formatı: `[sira => [sira, aktif, sayfa_kapsami, ceviriler[dil][soru|cevap]]]` — `sss_band_kontrol.php` `kapsam`/`sayfa_kapsami` uyumu destekler.
- Yasaklı `TSE` case-insensitive substring taraması (`stripos`) — içerikte geçmez.
- **Soru bandı byte ile ölçülür** (`strlen`, 20–150B); AR Q20 `ما متطلبات الأرضية؟` = 19 char / **36 byte** → band içi (char ölçümü yanlış FAIL üretir).
