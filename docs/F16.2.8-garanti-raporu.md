## 6. ADIM 3 — garanti.php JSON parse fix

```php
// ÖNCE (satır 24) — ham JSON basılırdı
$sure = (string) ($veri['garanti_suresi'] ?? '');

// SONRA
$sure = (string) $coz('garanti_suresi');

$istisna = (string) $coz('garanti_istisnalari');
```
