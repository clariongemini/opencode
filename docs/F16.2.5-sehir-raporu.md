3. **seo/check URL sözleşmesi** — `SeoService::sayfaCoz` dil öneki strip etmez; doğru test = `url=<prefixsiz path>&lang=<dil>`.

Döngü up/up(0)/down/up PASS; gocler `000043`; DB semantic equal 54/54; HTML 36/36; seo/check 36/36 key; LANG 0.
